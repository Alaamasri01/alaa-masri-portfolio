Concept C — Contemporary Luxury00 · Design system

Concept

An interiors-magazine reading of the work. Light paper, very large serif type, and asymmetric compositions that play one image against a warm sand block — the only “object” in the system besides the renders. Images bleed off one edge, never both, and titles break across lines in roman and italic, so every page has a direction. Page furniture shrinks to a folio number. Expressive in rhythm, but never decorative: no textures, no ornaments, no tilted images.
