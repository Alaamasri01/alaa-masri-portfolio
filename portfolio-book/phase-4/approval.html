Final design system — Hybrid C · A · B00 · System sheet

The system in one paragraph

One light editorial book. Warm ivory pages, oversized serif titles and asymmetric image compositions carry the identity (Concept C). Wherever the book states facts, such as project data, captions, tables, drawings or schedules, it switches to the precise Swiss structure of Concept A, set in the same fonts and colours. A few dark pages from Concept B act as deliberate pauses: selected project openers, section dividers, one or two image spreads and the back cover.

Where each concept lives

  • C · 70%Covers, profile, project spreads, contact — page rhythm, display type, sand block, bleeds
  • A · 20%Metadata rows, “Fig.” captions, folios, expertise table, technical sheets, schedules
  • B · 10%≤ 1 dark opener per 2 projects, section dividers, ≤ 2 dark image spreads, back cover

Rules that keep it one system

  • One blockAt most one sand block per page. Images may overlap it; never another image or text.
  • One bleedAn image bleeds off one outer edge (or top/foot), never across the spine.
  • One dominantEach spread has one dominant image; details are ≤ 2 and smaller.
  • TitlesSplit roman / italic, locked to column starts.
  • Dark pagesSame grid and type; only the palette inverts. Never two dark spreads in a row.
